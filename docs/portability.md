# 线上快照与可迁移调整

插件和配置以 2026-10-30 的运行实例为基准。仓库没有改变现有线上服务；为公开和迁移做了以下调整：

1. 排队插件从 `sessions` 配置读取允许的官方群会话，不再把原实例的会话 ID 写在源码中。
2. 活动创建通知的目标群通过 `WHALE_ANNOUNCEMENT_GROUP_IDS` 指定，群号到官方 OpenID 的映射仍放在管理插件的私密凭据文件中。
3. 备份告警目标群和来源主机由 `WHALE_BACKUP_GROUP_UMO`、`WHALE_BACKUP_SOURCE_HOST` 指定；官网侧 hook 从独立的私密设置文件读取通知地址。
4. 三类人格保留原有提示和工具列表，提示中的具体通知群号改为“由管理员配置”。群和 App 标识以占位符写入配置模板，凭据字段留空。
5. 第三方梗词库、前端字体和图标由脚本从固定上游提交获取；蓝色大肥鱼表情图需另行取得许可并导入。

数据库、消息、案例、订阅、草稿、账号登录态、API key、token、GitHub 私钥、SSL 证书以及个人记忆不会从线上导出到仓库。新部署需要重新授权外部服务，并建立空的运行数据。
